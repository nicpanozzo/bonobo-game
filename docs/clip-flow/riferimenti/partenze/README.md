# Immagini di partenza con le armi

Le immagini delle pose con gli oggetti: `<personaggio>_<presa>.png` (bastone, mira, palla, peso, sella), coi prompt di [../../pose-oggetti-prompt.md](../../pose-oggetti-prompt.md).
